# Public RSA certificate fixtures

Generated by `tools/generate-rsa-certificate-fixtures.py` using installed
Python cryptography 50.0.0. Certificates are valid 2025–2035. CertificateVerify
messages contain the standard server context and transcript hash 42 repeated 32
bytes. All retained files are public certificates or signatures; private test
keys remain only in a private temporary directory and are not committed.

The generator uses cryptography for key generation, signing and certificate
parsing. Its small ASN.1 reconstruction helper operates only on its own generated
certificate to create an absent-signature-parameters positive and strict SPKI
policy negatives, then reparses and independently verifies the new signature.
No fixture-generation helper is linked into the runtime verifier.

`provenance.json` pins all public bytes. OpenSSL chain/CV checks are recorded in
`artifacts/rsa-certificate-integration`. These fixtures supplement the complete
published Wycheproof primitive corpora; they do not replace those corpora.
